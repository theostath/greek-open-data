{# |tojson is Jinja2's htmlsafe_json_dumps: it escapes <, > and & and returns Markup, so a publisher-controlled series label cannot break out of the script element, and the value is not double-escaped either. Never |safe here. The option is delivered as application/json data, not as executable code, which is what lets script-src stay 'self' with no 'unsafe-inline'. It also means an ECharts option can never carry a JavaScript function — `formatter`, `renderItem` and the rest simply cannot survive JSON — though validate_spec refuses them by name regardless. The caption sits ABOVE the plot and carries the title, so app.js hides the option's own canvas title: one title, set in the page's type, instead of the same string twice. #}
